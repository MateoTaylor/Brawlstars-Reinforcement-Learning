## `enemies`

shape: `(9, 10)`, dtype: `float32`, per_entity

**Tracked-slot order** -- row k is the enemy holding tracker slot k (`slots: tracked`, core/slots.py): a slot is taken on the second consecutive sighting, kept through `slots.max_misses` unseen decisions, re-used lowest-free-first; an empty slot is all zeros. Same shape as entity order, not the same rows.
A `memory.*` row is masked by `memory.tracked`, not by the reveal, so it outlives the sighting: while its enemy is unseen it holds the last sighting, with `memory.seen` 0 and `memory.age_s` the time since.

|---|---|---|
| [0, 1) | `memory.tracked` | bool |
